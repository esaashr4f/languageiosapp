# Polyglot Atlas

Offline grammar guides for 100 languages, read in an iPhone home-screen app.

Before doing anything, read in this order:
1. `BRIEF.md` (the full instruction set; its Amendments section lists changes)
2. `PROGRESS.md` (one row per language)
3. the last entry of `SESSION_LOG.md` (what to do next)

Then follow the session loop in BRIEF.md section 6. Lesson format: `docs/CONTENT_FORMAT.md`.
Judgement calls go in `DECISIONS.md`, one dated line each. Ask nothing; stop only for money or the Apple ID.
Checks: `npm run lint:content -- <code>`, `npm run build:content`, `npm run stats`, `npm run test:tools`.
