## The idea

Class 3 nouns look like class 1 nouns. Both start with *m-* (or *mw-* before a vowel): *mtu* "person" is class 1, *mti* "tree" is class 3. The difference shows in two places. The plural of a class 3 noun takes *mi-*, not *wa-*: *miti* "trees". And the verb takes *u-* in the singular and *i-* in the plural: *mti unaanguka*, *miti inaanguka*. The school name of the pair, U-I, comes from those two verb prefixes.

What lives here? Almasi and colleagues and Thompson and Schleicher agree on the core: **trees and plants** (*mti*, *mwembe* "mango tree", *mnazi* "coconut palm"). Then come **body parts** (*mkono* "hand, arm", *mguu* "leg, foot", *mdomo* "mouth, lip", *moyo* "heart", *mwili* "body"), **natural features and forces** (*mto* "river", *mlima* "mountain", *moto* "fire", *mwezi* "moon, month", *msitu* "forest"), and a long tail of other things: *mlango* "door", *mfuko* "bag", *mji* "town", *mwaka* "year", *mkate* "bread".

Many class 3 nouns are made from verbs. Wiktionary analyses *mchezo* "game" as *m-* + *-cheza* "play" + *-o*, *mpango* "plan" as *m-* + *-panga* "arrange", and even *mkate* "bread" as *m-* + *-kata* "cut" + *-e*. Lesson 5.11 shows how to build such nouns.

A tree and its fruit often sit in different classes. The mango tree is *mwembe* (class 3); the mango is *embe* (class 5, lesson 3.5). Wiktionary derives *mwembe* from *mw-* + *embe*: the class prefix alone turns the fruit into the tree.

The adjective prefixes follow Thompson and Schleicher's rule of thumb from lesson 3.3: they copy the noun. Class 3 adjectives take *m-*, class 4 adjectives take *mi-*: *mti mrefu* "a tall tree", *miti mirefu* "tall trees".

## How it is built

The noun prefix before a vowel (lesson 1.6): *mw-* before *a*, *e*, *i* (*mwaka*, *mwembe*, *mwili*); plain *m-* before *o* (*moyo*, *moto*). The plural is always *mi-*: *miaka*, *miembe*, *miili*, *mioyo*, *mioto*.

Say "the tall trees are falling".

1. "Tree" is *mti*, class 3; plural *miti*, class 4.
2. "Tall": *-refu*. Class 4 adjective prefix *mi-*: *mirefu*.
3. Class 4 subject prefix *i-*, present *-na-*: *inaanguka*.
4. *Miti mirefu inaanguka.*

Say "the ball is not here".

1. "Ball" is *mpira*, class 3.
2. Class 3 subject *u-*; negative *ha-* in front: *hau-*.
3. Spot, here: *-po*. *Haupo*.
4. *Mpira haupo.* For the plural: *Mipira haipo.*

Say "the leg hurts".

1. *Mguu*, class 3: subject *u-*.
2. *-uma* "hurt, ache; bite", present: *unauma*.
3. *Mguu unauma.* (With "my", lesson 3.10, this becomes the everyday *mguu wangu unauma*; Thompson and Schleicher's example of the pattern is *ulimi wangu unauma* "my tongue hurts".)

The full set for classes 3 and 4: subject prefixes *u-* and *i-*, negatives *hau-* and *hai-* (Almasi and colleagues, table 10.1); adjective prefixes *m-* and *mi-* (their table 13.2; Wiktionary's concord tables).

## Where it applies

- **Trees and plants**: *mti*, *mwembe*, *mnazi*, *mpira* (originally the rubber plant, now also "ball", Wiktionary).
- **Body parts**: *mkono*, *mguu*, *mdomo*, *moyo*, *mwili*. (Others are in classes 5 and 7: *jicho* "eye", *kichwa* "head".)
- **Nature**: *mto* "river", *mlima*, *moto*, *mwezi*, *msitu*.
- **Time**: *mwaka* "year", *mwezi* "month". *Mchana* "daytime" (lesson 2.8) is class 3 with no plural.
- **Objects and places**: *mlango*, *mfuko*, *mzigo*, *mkate*, *mji*.
- **Nouns made from verbs**, many with final *-o*: *mchezo*, *mpango*, and loans such as *mtihani* "exam" from Arabic (Wiktionary).
- **Subject left out**: *Inaanguka* "they (the trees) are falling"; *Unauma* "it (the leg) hurts".
- **Having and being somewhere**: *Mfuko una mkate*; *Msitu uko karibu*.
- **Adjective predicates**: *Mzigo ni mzito*; *Mikono ni michafu*.

## Watch out

**Do not give a class 3 noun class 1 agreement.** *\*Mti anaanguka* treats the tree as a person. *Mti unaanguka.* The adjective prefix is *m-* for both classes, so it never helps: check the plural or the verb.

**Do not make class 3 plurals with *wa-*.** *\*Wati*, *\*wakono* are wrong. Class 3 nouns take *mi-*: *miti*, *mikono*. Almasi and colleagues give the test: a *mw-* noun takes *wa-* only if it names a person (or the two animate words *mnyama* "animal" and *mdudu* "insect"); otherwise *mi-*. So *mwalimu*, *walimu*, but *mwaka*, *miaka*.

**Do not merge the vowels in class 4.** Class 2 merges *wa-* with a vowel (*walimu*), but *mi-* stays as it is: *miaka*, not *\*meaka*; *miiba* "thorns", with both *i*s.

**Do not read *unauma* as "you".** The class 3 prefix *u-* is the same as "you (one person)" from lesson 2.2. *Unauma* alone could mean "you bite" or "it hurts". The noun or the context decides: *Mguu unauma* is about the leg.

**Do not confuse *hau-* with *hu-*.** "You don't" is *hu-* (*hulali* "you're not sleeping"); class 3 "it doesn't" is *hau-*, with the *u-* kept: *Mti hauanguki* "the tree isn't falling", but *huanguki* "you aren't falling".

**Do not assume every *m-* noun is class 1 or 3.** *Mvua* "rain" (lesson 1.3) is class 9 and has no *mi-* plural. Its adjective shows it: "heavy rain" is *mvua kubwa*, with the class 9 form, not *\*mvua mkubwa*. Lesson 3.6 explains the nasal class.

**Do not use *mw-* before *o*.** *\*Mwoto* and *\*mwoyo* are wrong: *moto*, *moyo*. Their plurals keep the *o*: *mioto*, *mioyo*.

**Do not copy class 1 *a-* to class 3 by analogy with *mwalimu*.** *\*Mwaka anaanza* treats the year as a person. *Mwaka unaanza.*

## Connections

The tree-and-fruit pair *mwembe* / *embe* has a loose parallel in Spanish *naranjo* "orange tree" / *naranja* "orange" and *manzano* / *manzana*, where a change of ending turns fruit into tree. Swahili does it with a change of class prefix, and the agreement on every following word changes with it.

## Exercises

1. Give the plurals of *mlima*, *mwembe* and *moyo*.
2. Say "the river is long" and "the rivers are long".
3. Take apart *Haiwaki* and say what it could be about.
4. Say "the bag has a ball".
5. Correct *\*Mwaka anapita.*
6. Correct *\*Wakono ni wachafu.*
7. Translate *Mikate si mitamu.*
8. *Mwalimu mzuri* and *mwaka mzuri*: same adjective prefix. Add a verb to each so that the difference shows.
9. Why does the plural of *mwiba* have two *i*s, when the plural of *mwalimu* has only one *a*?

## Worked answers

1. *Milima*; *miembe* (the *mw-* becomes *mi-*, the stem *-embe* stays); *mioyo* (plain *m-* before *o*, plural *mi-*).
2. *Mto*, class 3: adjective *m-*: *Mto ni mrefu.* Class 4: *Mito ni mirefu.*
3. *Ha-*: not. *-i-*: class 4 subject. *-wak-*: burn. *-i*: negative final vowel. "They aren't burning", about class 4 things, for example *mioto* "fires".
4. *Mfuko* is class 3: *u-* + *na*: *Mfuko una mpira.*
5. *Mwaka* is class 3 (plural *miaka*), not a person: *Mwaka unapita.*
6. *Mkono* is class 3; the plural is *mi-*, and so is the adjective: *Mikono ni michafu.*
7. *Mikate*: class 4 "loaves". *Si*: is not. *Mitamu*: class 4 "tasty". "The loaves aren't tasty" or "the bread isn't good".
8. *Mwalimu mzuri anafika* (class 1 *a-*); *mwaka mzuri unaanza* (class 3 *u-*). The verb prefix shows the class the adjective could not.
9. Class 2 *wa-* merges with a following vowel (*wa-* + *-alimu* → *walimu*). Class 4 *mi-* does not merge: *mi-* + *-iba* → *miiba*.
