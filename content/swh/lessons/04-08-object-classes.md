## The idea

Things can be objects too, and every class has an object prefix for them. The good news: apart from class 1, the object prefix of each class is identical to its subject prefix. Almasi and colleagues state it in one line; Wiktionary's appendix agrees ("all the class object concords are the same as for the subject, except class 1"). So a book (class 7) is *-ki-*, books (class 8) *-vi-*, a house (class 9) *-i-*, houses (class 10) *-zi-*. *Nimekisoma* "I have read it" (the book).

That gives you the forms. The harder question is when to use them. Lesson 4.7 said: with a person, put the object prefix in. With a thing, it is optional, and choosing it says something.

**Without an object prefix**, the noun object follows the verb: *Nimesoma kitabu* "I've read a book" or "I've read the book", neutral.

**With an object prefix and the noun**, the object is singled out as a particular, known thing. Polomé's example: a servant asked *Umeleta gazeti?* "have you brought the newspaper?" answers *Nimeleta* "I have". If the question puts weight on that newspaper, *Umelileta gazeti?*, the answer is *Nimelileta*. Almasi and colleagues say the object prefix is used when one wants to emphasise the object, or when a demonstrative or possessive is present (*kitabu hiki*, *kitabu changu*). Wpgrammar puts it in terms of definiteness: the object prefix with a noun object is "more frequent when a definite reading is preferred". Swahili has no word for "the"; the object prefix does part of that work for objects.

**With an object prefix and no noun**, the prefix is the pronoun "it, them": *Walivinunua* "they bought them" (Thompson and Schleicher), once you know what *them* refers to.

Thompson and Schleicher give a third use: object prefix and noun together for contrast. *Alizitaka ndizi* "he wanted *bananas*" (not apples).

### Object first

Lesson 3.14 told you to keep subject, verb, object until now. Wpgrammar notes that because the verb carries both subject and object prefixes, the basic order can change to emphasise part of the sentence. One such change puts a known object at the front, as a topic: "This book, I've read it." When you do that, use the object prefix. It is what ties the fronted noun to its verb: *Kitabu hiki nimekisoma.* Without it, *kitabu hiki* would hang at the front with nothing in the verb pointing back to it.

### The reflexive -ji-

"Himself", "myself", "themselves": Swahili has no separate pronoun for these. Thompson and Schleicher explain that the meaning is carried by an object prefix, *-ji-*, the **reflexive** marker, which says that the object is the same as the subject. It is the same for every person and class (Polomé). *Alijiangalia* "he looked at himself", *mnajificha* "you are hiding (yourselves)" (both Thompson and Schleicher).

Some verbs with *-ji-* have their own meaning. *-funza* is "teach"; *-jifunza* "teach oneself" is the everyday verb for "learn" (Wiktionary: "-funza (reflexive) to learn"). Learn *-jifunza* as a word, but remember that *-ji-* is an object prefix inside it: in a command it behaves like one (lesson 4.10; wpgrammar: *jifunze!*, not *\*jifunza!*).

## How it is built

Say "we didn't drink the water".

1. Negative "we": *hatu-*. Negative past: *-ku-*.
2. The water is particular, so add the object prefix: *maji* is class 6, object *-ya-*.
3. Root *-nyw-*. A short verb, but the object prefix carries the stress: no *ku-*.
4. *Ha-tu-ku-ya-nyw-a maji*: *Hatukuyanywa maji.* (Almasi and colleagues give *Niliyanywa maji* "I drank the water".)

Now put the object first: "The rice, have you cooked it?"

1. Topic first: *Mchele*, class 3.
2. "You" + perfect: *u-me-*. Object prefix class 3: *-u-*.
3. *U-me-u-pik-a*: *Mchele, umeupika?*

And "the child hurt himself".

1. Subject class 1, past: *a-li-*.
2. The object is the subject itself: *-ji-*.
3. Root *-umiza* "hurt": *a-li-ji-umiz-a*. *Mtoto alijiumiza.*

## Where it applies

- **Every class**: *-u-* (3, 11, 14), *-i-* (4, 9), *-li-* (5), *-ya-* (6), *-ki-* (7), *-vi-* (8), *-zi-* (10), *-ku-* (15, 17), *-pa-* (16), *-m(w)-* or *-mu-* (18). Thompson and Schleicher give *anaupenda*, *anaipenda*, *analipenda*, *anayapenda*, *anakipenda*, *anavipenda*, *anazipenda* and so on.
- **A known or particular thing**: *Nimekisoma kitabu*, especially with *hiki*, *changu* and the like (Almasi and colleagues).
- **"It, them" for a thing already mentioned**: *Nimelileta*. *Walivinunua.*
- **Contrast**: *Alizitaka ndizi.*
- **An unknown or general "it"**: Almasi and colleagues note that when the thing is not specified, the class 9 prefix is used: *Niliinunua* "I bought it".
- **The object first**: *Kitabu hiki nimekisoma.* *Mchele, umeupika?*
- **Infinitives as objects**: class 15 *-ku-*: *Tutakupenda kusoma* "we'll like (the) reading" (Almasi and colleagues). Lesson 4.12 says more.
- **Reflexives**: *-ji-* for every subject: *nilijiona*, *alijiona*, *tulijiona*, *walijiona*.
- **Verbs that are reflexive in meaning**: *-jifunza* "learn", *-jificha* "hide (oneself)".
- **One object prefix per verb.** With two objects, Almasi and colleagues say: a living being takes the object prefix and the thing stays a noun (*nilimpa kitabu* "I gave him a book"); with two things, the direct object takes it (*nilikiona kitabu mfukoni* "I saw the book in the bag").

## Watch out

**Class 1 is the exception.** *\*Ninaapenda mtoto* uses the class 1 subject prefix as an object. The object prefix is *-m-*: *Ninampenda mtoto* (lesson 4.7).

**Do not add an object prefix to every thing.** *Nimekisoma kitabu* is "I've read the book (we spoke of)". For "I've read a book", *Nimesoma kitabu* is the neutral choice. Overusing the prefix sounds insistent.

**Do not front an object without an object prefix.** *\*Kitabu hiki nimesoma* leaves the fronted noun unlinked. Say *Kitabu hiki nimekisoma.*

**Match the prefix to the object, not the subject.** *\*Mtoto alikivunja vikombe* mixes class 7 and class 8. "The child broke the cups": *Mtoto alivivunja vikombe.*

**Do not put two object prefixes in one verb.** *\*Nilimkipa* (him + it) is not possible. Say *Nilimpa kitabu*, or *Nilimpa* if the book is clear.

**"Myself" is not a word after the verb.** *\*Nilimwona mimi mwenyewe* does not mean "I saw myself". Say *Nilijiona.*

**Do not confuse reflexive *-ji-* with the class 5 prefix *ji-*.** *Jicho* "eye" begins with the class 5 noun prefix. In *alijiona*, *-ji-* sits in the object slot after the tense.

**Do not keep *ku-* before *-ji-*.** *\*Alikujiona* is wrong: *alijiona*. Any object prefix, *-ji-* included, carries the stress.

## Connections

Spanish has the same "object first, then a pronoun" pattern: *Este libro lo he leído*. The fronted noun is picked up by *lo* exactly as *kitabu hiki* is picked up by *-ki-*. Spanish *se* and French *se* are the closest parallel to *-ji-*, though they change for person (*me*, *te*) where *-ji-* does not. Japanese uses a separate word, 自分.

## Exercises

1. Say "I've cooked the meat (*nyama*, class 9)" with and without the object prefix. What is the difference?
2. *Umezinunua ndizi?* Answer "yes, I've bought them" and "no, I haven't bought them yet".
3. Put the object first: "These trousers, I sewed them."
4. Say "we hid ourselves" and "they are washing themselves" (*-osha*).
5. Correct *\*Nilikitupa vitabu.*
6. Correct *\*Kofia yangu nimepoteza.*
7. Correct *\*Ninafunza Kiingereza* meant as "I'm learning English".
8. Take apart *hawakuyachukua* and say what *-ya-* might stand for.

## Worked answers

1. *Nimepika nyama* "I've cooked (some/the) meat", neutral. *Nimeipika nyama* "I've cooked the meat (that one)": the object prefix singles it out.
2. *Ndiyo, nimezinunua.* *Hapana, sijazinunua (bado).* Class 10 object *-zi-*, in the perfect and in "not yet".
3. *Suruali hii niliishona.* *Suruali* is class 9: object *-i-*, so *ni-li-i-shon-a*, with two *i*s in two slots.
4. *Tulijificha.* *Wanajiosha.* *-ji-* for every person.
5. The object prefix must match *vitabu*, class 8: *Nilivitupa vitabu.*
6. A fronted object needs the object prefix: *Kofia yangu nimeipoteza.*
7. "Learn" is the reflexive *-jifunza*: *Ninajifunza Kiingereza.* *Ninafunza Kiingereza* means "I teach English".
8. *Ha-wa-ku-ya-chuku-a*: "they didn't take them". *-ya-* is class 6: something like *maji*, *mafuta*, *majani* or *makoti*.
