## The idea

Every verb you have built so far states something: it happens, it happened, it will happen. Swahili has a second kind of verb form for things that are wanted, asked for, proposed or allowed rather than stated. This is the **subjunctive**: the form of the verb used for an action that someone wishes or requests, not one that is reported as fact.

Its shape is simple. Take the subject prefix, leave the tense slot empty, add the root, and change the final vowel to *-e*: *u-som-e*, *usome* "(you) read, please; you should read". Thompson and Schleicher give the formula as subject prefix + verb with *-a* changed to *-e*. Wpgrammar describes the subjunctive as marked by "the lack of any Tense-Aspect-Mood prefix" and the *-e*.

So the final vowel slot, which you have seen hold *-a* and *-i*, now holds a third value. Each one goes with a kind of verb: *-a* for statements, *-i* for the negative present, *-e* for the subjunctive.

The usual adjustments follow from what you know:

- **Loan verbs** have no final vowel to change, so the subjunctive is the subject prefix + the stem: *ujibu* "(you) answer", *turudi* "let's go back" (Thompson and Schleicher). Only the empty tense slot shows the mood.
- **Short verbs** drop *ku-*: *wale* "let them eat" (Thompson and Schleicher), *nile* "let me eat" (Wiktionary). There is no tense marker to avoid stressing, and the subject prefix carries the stress (lesson 4.4).
- **-enda** loses its *kw-* too: *niende* "let me go". With "we", Wiktionary gives both *twende* and *tuende*; *twende* "let's go" is one of the commonest words in the language.

This lesson covers the uses where the subjunctive stands on its own as a request or proposal. Lesson 4.11 covers the uses after another verb ("I want you to...") and the negative.

**Polite requests.** A bare command (lesson 2.7) is blunt. Almasi and colleagues say Swahili speakers do not give bare commands to their elders but make requests, and the request form is the subjunctive with *u-* or *m-*: *ukae* "please sit", *mkae* (to several). With *tafadhali* it is politer still: *Tafadhali ujibu barua yetu* "please reply to our letter" (their example).

**"Let's" and "let me".** With *tu-* the subjunctive proposes: *Tuende* "let's go" (Thompson and Schleicher). With *ni-* it offers or asks permission: *Nisome?* "shall I read? may I read?" (Thompson and Schleicher list asking permission as a use of its own.)

**"Let him", "may it".** With a third-person or class prefix it expresses a wish or instruction about someone else: *Aje kesho* "let him come tomorrow, he should come tomorrow".

**Commands with an object prefix.** Here is the promise of lesson 2.7. A command that contains an object prefix does not end in *-a*: it ends in *-e*. *Nisaidie!* "help me!", *Zichukue!* "take them!" (Thompson and Schleicher, class 10). Note what is missing: there is no subject prefix. The form is object prefix + root + *-e*, and *-eni* for several listeners: *nisaidieni!*. Polomé calls this the "adhortative" and treats it as the command used "with an object infix". Wpgrammar's table: *angalia!* "look!" but *mwangalie!* "look at her!", plural *mwangalieni!*. Loan verbs keep their vowel: *nijibu!* "answer me!", *nijibuni!*. And because *-ji-* is an object prefix, the command "learn!" is *jifunze!* (wpgrammar).

Why does an object prefix trigger *-e*? The sources describe the rule without explaining it, so this guide will not offer a reason.

## How it is built

Politely ask one person to open the window.

1. Root: *-fungua* "open", root *-fungu-*.
2. A request to "you": subject prefix *u-*.
3. No tense marker. Final vowel *-e*.
4. *U-fungu-e*: *Tafadhali, ufungue dirisha.*

Propose "let's eat now".

1. Root *-l-*, a short verb. "We": *tu-*.
2. Subjunctive: no tense, no *ku-*, final *-e*: *tu-l-e*.
3. *Tule sasa.*

Tell someone "read it!" (the book).

1. The object is *kitabu*, class 7: object prefix *-ki-*.
2. A command with an object prefix: no subject prefix, final *-e*.
3. *Ki-som-e*: *Kisome!*

## Where it applies

- **Polite requests to "you"**: *usome*, *ukae*, *umsaidie* "(please) help him". Add *tafadhali* for extra politeness.
- **Requests to several people**: *mkae*, *msome*, *mrudi*.
- **"Let's"**: *tusome*, *tule*, *twende*, *tuanze* "let's begin".
- **"Shall I?", "may I?"**: *Nisome?*, *Niende?*, *Nifungue dirisha?*
- **"Let him, let them, may it"**: *aje*, *wale*, *mvua inyeshe* "may it rain", *kiti kikae hapa* "let the chair stay here".
- **Commands with any object prefix**: *nisaidie!*, *mwangalie!*, *kisome!*, *zichukue!*, *iweke mezani!*; plural with *-eni*.
- **Reflexive commands**: *jifunze!*, *jifiche!* "hide!"
- **Commands of short verbs with an object**: the object prefix replaces *ku-*: *kula!* "eat!" but *kile!* "eat it!" (a class 7 thing); Almasi and colleagues give *ile!* "eat it!" for a banana.
- **After *-ambia*, *-taka*, *lazima* and other words**: lesson 4.11.

## Watch out

**No tense marker in the subjunctive.** *\*Unasome* and *\*Utasome* put a tense in front of *-e*. The subjunctive has an empty tense slot: *Usome.*

**No *ku-* with short verbs.** *\*Tukule* or *\*Ukunywe* keep a stress-bearer that is not needed: *Tule*, *Unywe*.

**Do not give a loan verb an *-e*.** *\*Ujibe*, *\*Turude* invent vowels. Loan verbs do not change: *Ujibu*, *Turudi*.

**A command with an object never ends in *-a*.** *\*Nisaidia!* is wrong; *nisaidia* is not a word. Say *Nisaidie!* Likewise "read it!" is *Kisome!*, not *\*Kisoma!*

**Do not add *u-* to an object command by accident.** *Umsaidie* "(would you) help him" is a polite request with subject *u-*. *Msaidie!* "help him!" is the command with only the object prefix. Both are correct, and they differ in politeness. But *msaidie* can also be read as the 2PL request "(you all) help": context decides.

**"Help me!" and "let me help" look the same.** Thompson and Schleicher point out that *nisaidie* can be either: with *ni-* as object, "help me!"; with *ni-* as subject, "let me help". Context decides.

**Do not use the future for "let's".** *Tutakwenda* states "we will go". The proposal is *Twende*.

**The irregular commands stay irregular only when bare.** *Njoo!* and *nenda!* are commands; the subjunctive of the same verbs is regular: *uje*, *uende* (Almasi and colleagues). The plural request is *mje*; for *-enda*, Wiktionary gives *mwende*, while Almasi and colleagues print *mende*.

## Connections

Spanish uses its subjunctive in the same three places: polite and negative commands (*siéntese*, *no comas*), "let's" (*vamos*, *comamos*) and "let him" (*que venga*). French *qu'il vienne* matches *aje*. Japanese covers "let's" with a separate ending (行こう) and polite requests with ください; Swahili uses one form for all of these.

## Exercises

1. Make polite requests to one person: "sit", "taste (it)" (*-onja*, without an object), "answer".
2. Make the same requests to several people.
3. Say "let's begin", "let's go", "let's eat".
4. Ask "shall I close the door?" and "shall we wait?" (*-subiri*).
5. Give the commands "help us!", "call them!" (*-ita*), "take it!" (*kikombe*).
6. Correct *\*Tukunywe chai.*
7. Correct *\*Nisaidia!*
8. Take apart *zichukueni* and translate it.

## Worked answers

1. *Ukae*, *uonje*, *ujibu*. Subject *u-*, no tense, *-e* (none for the loan verb *-jibu*).
2. *Mkae*, *mwonje*, *mjibu*. 2PL subject *m-*, written *mw-* before a vowel, as in *mwende*.
3. *Tuanze*, *twende*, *tule*.
4. *Nifunge mlango?* *Tusubiri?* (*-subiri* is a loan verb.)
5. *Tusaidie!* *Waite!* *Kichukue!* Object prefix + root + *-e*, no subject prefix.
6. No *ku-* in the subjunctive: *Tunywe chai* "let's drink tea".
7. A command with an object prefix ends in *-e*: *Nisaidie!*
8. *Zi-chuku-eni*: object class 10, root "take", *-e* + *-ni* for several listeners. "Take them!" (to several people), for something like *ndizi* or *chupa*.
